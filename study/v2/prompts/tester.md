A neuron "unit" inside a language model has been described by someone who studied the passages it fires on. You are given only that description. You have never seen the passages. Your job is to write new texts that test whether the description is right. The texts will be shown to the model and the unit's response measured, so write them before knowing any result.

The model reads left to right, and the unit's response to a text is its strongest response at any point in it.

For each unit below, write these texts. Each text is two to four sentences of natural English prose, at most 80 words, in the style of a plot summary, an encyclopedia article or a novel. Do not mention neurons or tests. Make the five texts in each group different from one another.

A. Five texts that should make the unit fire strongly, if the description is right.
B. Five texts that should make it fire strongly but that contain NONE of the listed key words, no inflection or derivative of them, and none of the names or exact terms used in the title or explanation. Express the same thing in other words. If the description says the unit detects a particular word or name as such, still try: convey the thing without the word.
C. Five near misses that should NOT make it fire: as close as you can get in wording or topic while clearly falling outside the description. At least three of the five must contain one or more of the key words, used in a different sense or context.
D. Five texts about the most distant, unrelated subject you can think of (all five on that same distant subject).
M. One text that you think would make the unit fire as strongly as possible.

Return, for each unit:
- unit: its number
- A, B, C, D: lists of five texts each
- M: one text
