# Research notes behind the roadmap

These are the working notes from the sweep of 8 November 2026. They are kept as written, so the roadmap's claims can be traced.

- Files starting with `a` audit this repository: the study, its robustness work, the method as code, the pre-registration and the working session.
- Files starting with `l` review the outside literature, one topic each.

How they were made: each file was written by an AI research agent that read the repository or searched the web. For the literature files, a second agent then checked every citation against the publisher, arXiv or Crossref and corrected the file in place; its changes are listed under "Check log" at the end of each file. Anything it could not confirm is marked `[UNVERIFIED]`.

How to read them: they are leads, not findings. Papers from 2025 and 2026 are recent and thinly reviewed. Confirm a source yourself before citing it in a paper. Numbers from the Batman study name the committed file they come from.

No experiment, model or pipeline was run to produce any of this.
