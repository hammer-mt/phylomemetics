# Registered designs

One file per design. Each was registered on 8 November 2026, before any data was collected for it. None has been run.

A registered design is a short plan: the question, the prediction, the result that would refute it, the data, the method and the cheap rival it has to beat. It is not a full pre-registration. To run one, expand it into a pre-registration with a frozen analysis plan and a power calculation, as was done in [`../../preregistration/`](../../preregistration/), and commit that before generating any test data.

Every design was drafted by one AI agent from the research notes and then attacked and revised by a second. The "Reviewer note" in each file says what the reviewer changed and what weakness remains.

These files are generated by `../build.py` from `../ideas.json`. Edit the JSON, not the files.
